**規格以外新增的欄位（實作需要，請知悉）**：

- designDecision 的 `topic`：validator 要判斷「委派或方案子選擇是否碰到排除類型」，必須有一個宣告欄位；§20 只列了 `kind`、`directionRef`、`dependsOn`。`excludedKinds` 的值域也用這組 topic（copy、brand_asset、external_requirement、new_token、new_component、raw_value_exception、platform、write_scope）。
- designDecision 的 `confirmedWith`：用來分辨「隨方案一起確認」與「逐列確認」，否則 T86 只能靠時間戳推測。
- `plan.importChecks`、`inventory.componentFontChecks`、`ledger.reworkRounds`、ruleCheck 的 `findingRef`／`affectsDelivery`、copy 的 `decisionRef`、externalRequirement 的 `sourceKind`／`affectsDelivery`／`decisionRef`。
- 都是選填；舊 run 沒有時只產生 notice，schemaVersion 維持 `1.2`。建議下次修規格時把它們寫進 §20。

**限制**：validator 只能檢查 agent 宣告的 `kind`／`topic`；agent 把文案題標成 `topic: detail` 這類錯標，程式攔不到，靠 skill 規則與 Plan 摘要讓使用者看見。ruleCheck 的對比偵測（T94）是文字比對（contrast、對比、`n:1`），屬啟發式。
